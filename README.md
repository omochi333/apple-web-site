# りんごの森 🍎

絵本のような雰囲気で、6種類のりんごをくらべられる小さな図鑑です。
ふじ・つがる・王林・ジョナゴールド・紅玉・シナノゴールドの甘み、酸味、食感、旬の目安を紹介しています。

- 「あまいのが好き」「酸味を楽しみたい」「お菓子づくりに」で絞り込み
- 全品種を一覧できる比較表と、おいしい豆知識
- スマートフォン対応。JavaScriptが無効でも全品種と比較表を閲覧できます

味の評価は相対的な目安であり、実測値ではありません。産地や栽培条件、保存状態によって違いがあります。

## GitHub Pagesで公開・閲覧する

HTML・CSS・JavaScriptとオリジナルSVGだけの静的サイトです。依存パッケージのインストールやビルドは不要です。

1. この変更をリポジトリの公開用ブランチ（通常は `main`）にマージします。
2. GitHubで **Settings → Pages → Build and deployment** を開きます。設定にはリポジトリの管理権限が必要です。
3. **Source** に **Deploy from a branch** を選びます。
4. **Branch** に `index.html` のあるブランチ（通常は `main`）、フォルダーに **/ (root)** を選び、**Save** を押します。
5. **Actions** タブで `pages build and deployment` が成功するのを待ちます。初回の公開には数分かかることがあります。
6. **Settings → Pages** の **Visit site** から閲覧できます。標準の公開URLは次のとおりです。

   **https://omochi333.github.io/apple-web-site/**

このURLはPagesの設定とデプロイが完了してから有効になります。404の場合は、公開ブランチ・ルートフォルダー・Actionsの結果を確認してください。リポジトリ名やカスタムドメインを変更した場合は、Pages設定に表示されるURLを使ってください。

以降は、選択した公開ブランチに変更が入ると自動的に更新されます。

## ローカルで閲覧する

`index.html` をブラウザーで開くだけでも閲覧できます。
HTTPサーバーで確認する場合は、Python 3がある環境で、リポジトリのルートから次を実行してください。

```sh
python3 -m http.server 8000
```

**http://localhost:8000/** を開きます。停止は `Ctrl+C` です。
Node.js / npmもある場合は、同じサーバーを `npm start` で起動できます（`npm install` は不要）。

## ファイル構成

- `index.html`：品種データ、比較表、豆知識
- `style.css`：絵本風のデザイン、レスポンシブ対応
- `script.js`：品種の絞り込み
- `orchard.svg` / `favicon.svg`：オリジナルイラスト

品種の情報を更新するときは、カードと比較表の両方を更新してください。
既存の自動テスト・ビルド・リンターの設定はありません。変更後はブラウザーで各フィルター、比較表、狭い画面での表示を確認してください。

## 日本で一番リンゴを消費している都道府県は？

家庭での購入数量を目安にすると、**青森県（青森市）**です。総務省「家計調査」の2023～2025年平均では、青森市の二人以上の世帯における1世帯当たりのりんごの年間購入数量は**20,290g（約20.3kg）**で、都道府県庁所在市・政令指定都市の中で1位です。

※これは都市別の購入数量の比較であり、都道府県全体の総消費量や、1人当たりの実際に食べた量の順位を示すものではありません。

出典：[総務省統計局「家計調査」品目別ランキング（2023～2025年平均・果物）](https://www.stat.go.jp/data/kakei/5.html)、[りんご購入量ランキング（同調査のデータ掲載）](https://www.sumigo.jp/indicators/meal-quantity/city/apple-quantity)
